# Product Overview

## What this is

A Todo application for creating, organizing, and tracking tasks. The goal is a
simple, reliable tool that lets a user capture what they need to do and mark
things complete without friction.

## Target users

- Individuals managing a personal task list.
- (Future) small teams sharing a list.

## Core features

- Create, edit, and delete tasks.
- Mark tasks as complete or incomplete.
- Organize tasks (lists, tags, or due dates).
- Filter and sort tasks (e.g. active, completed, by due date).

## Product principles

- Keep the core flow fast: adding and completing a task should take one action.
- Favor clarity over feature count; avoid cluttering the primary task view.
- Persist data reliably — a user should never lose a task.
